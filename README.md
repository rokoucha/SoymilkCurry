# SoymilkCurry

Poor Man's DVR Tuner server

## 特徴

- チューナーとチャンネルまわりだけMirakurun互換APIです
- TSを一切解析しません
- 同じチャンネルへのアクセスは良い感じに分岐します
- デコーダーもDVBデバイスも追加対応をしていなので手動でパイプで繋いでください

## セットアップ

[リリース](https://github.com/rokoucha/SoymilkCurry/releases)より最新のバージョンをダウンロードしてください。

設定は[サンプル](https://github.com/rokoucha/SoymilkCurry/blob/main/config.example.yml)を参考にしてください。実行時に第一引数で設定ファイルへのパスを指定してください。
